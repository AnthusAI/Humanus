# 能泄露你住在哪里的声音

在当今快速发展的数字环境中，值得注意的是，隐私不仅仅是一个技术问题，它也是一个人的问题。苏黎世联邦理工学院的研究人员于2025年12月发布了1,250份访谈，这些发现确实具有变革性。

Waymo的无人驾驶汽车在四座城市约5000万英里的行驶中，碰撞率比人类驾驶员低68%。“我还没看过UI代码，”这位工程师写道。该公司没有说明其中有多少起碰撞被报告给了警方。

此外，这项研究证明了强大工具的关键作用。它深入探讨了分享与披露之间错综复杂的关系，强调了在复杂环境中前行的必要性。专家表示，这项技术将永远不断进步。

归根结底，分享与披露之间的界限正在移动。未来看起来很光明，只有时间才能告诉我们接下来会发生什么。
